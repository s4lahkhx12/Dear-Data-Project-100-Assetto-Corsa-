# Dear-Data-Project-100-Assetto-Corsa-
## Project idea
I plan to collect 100 genuine GT4 lap times at Spa-Francorchamps in Assetto Corsa Competizione.

## Aim
To explore lap-time variation using a visualisation created in Processing (Java).
